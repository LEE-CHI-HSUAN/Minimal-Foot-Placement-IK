# Minimal Foot IK

A lightweight, beginner-friendly foot placement IK solution for Unity. This package provides simple scripts to ensure your character's feet correctly align with uneven terrain.

## Features

- **Easy Integration**: Downloadable via Unity's Package Manager.
- **Multiple IK implementations**: Ranging from simple to advanced, including standard Animator IK, Animation Rigging, and two-bone constraint.
- **Visual Debugging**: Includes Gizmos to help you visualize raycasts and ground alignment.
- **Sample Scene**: A playground with a controllable character and a gallery displaying the results of each implementation.

## Requirements
- Unity 2022.3 or higher.
- [Animation Rigging](https://docs.unity3d.com/Packages/com.unity.animation.rigging@1.3/manual/index.html) (Installed automatically via dependency).

## Installation

1. Open the **Package Manager** (*Toolbar > Window > Package Manager*).
2. Click the `+` icon and select **Add package from git URL**.
3. Paste the following URL:
   ```
   https://github.com/LEE-CHI-HSUAN/Minimal-Foot-Placement-IK.git
   ```
